# Конвертор валют

**Это конвертор валют. У него есть 6 команд:**
```python
/start
/help
/history
/rubles_to_dollars
/dollars_to_rubles
/my_city
```
**Первая команда** запускает бота и сразу выводит список доступных команд.
**Вторая команда** выводит список команд отдельно. На случай если пользователь забыл команды и удалил сообщение.
**Третья команда** выводит историю запросов пользователя.
**Четвёртая команда** конвертирует рубли в доллары по актуальному курсу.
**Пятая команда** конвертирует доллары в рубли по актуальному курсу.

Актуальность курса поддерживается Центральным Банком Российской Федерации.
Бот напрямую подключён к API Центрального Банка Российской Федерации, потому курс валют на столько актуален, на сколько это возможно.

Если пользователь введёт что-либо кроме этих 5 команд, то бот ответит, что не понимает текст, и может общаться только командами.

## Как работает API
Выбранный мной API, это **API Центрального Банка Российской Федерации**. 
Это API предоставляет актуальный курс доллара. Каждый раз когда пользователь конвертирует валюту используя бота,
бот отправляет запрос на API Центрального Банка Российской Федерации, получая курс доллара, актуальный именно на тот момент,
когда пользователь обращается. После чего бот в зависимости от выбранной функции или умножает число пользователя на курс (если пользователь ввёл число долларов),
или наоборот делит число пользователя на курс (если пользователь ввёл число в рублях). 



Запускать код необходимо через файл **main.py**, после этого сам бот будет активен. Чтоб использовать телеграмм бота,
необходимо перейти по ссылке (она даётся во время создания бота), после чего необходимо нажать **СТАРТ**


**endpoint API проекта:**
1) **https://www.cbr-xml-daily.ru/daily_json.js** - **API Центрального Банка Российской Федерации** (нужен, чтоб узнать курс)
2) **https://api.ipify.org?format=json** - **API IPfy** (нужен, чтоб узнать IP-адрес пользователя)
3) **https://ipinfo.io/{ай-пи_адрес_человека}/geo** - **API IPinfo** (нужен, чтоб узнать город пользователя через IP-адрес)



## Цель бота
Бот нацелен на то что бы дать людям понять, каковы их сбережения в рублях и долларах.
Так как курс валют постоянно меняется, бот проверяет его каждый раз перед отправкой сообщения.
В итоге пользователю не нужно выходить из телеграмм, чтоб узнать курс.

**Пример ситуации, где этот бот будет полезен**: На пример если у бизнес-партнёров переписка в телеграм, и к ним поступил крупный заказ от их иностранных партнёров (на пример Американская компания желает купить у наших бизнес-партнёров 10000 матрёшек для продажи в Нью-Ёрке (обмен культурным кодом)). Однако для этого необходимо узнать, хорошая ли за это идёт оплата (если бизнес не приносит прибыли, то это не совсем бизнес). Однако курсы валют постоянно меняются, и проверять курс валюты каждый раз неудобно, при том что скорее всего придётся считать цену в иностранной валюте. Здесь и помогает этот телеграм бот. С его помощью можно за секунды узнать достойная ли цена, переведя валюту по актуальному курсу. 

## Чем бот отличается от других
Этот телеграм бот отличается от других простотой команд. Всегда понятно что конкретная команда делает. К тому же курс на столько актуален, на сколько это возможно из-за использования **API Центрального Банка Российской Федерации**, где курс актуален всегда. К тому же, кроме перевода валюты, этот бот способен выводить город в котором находится человек.
